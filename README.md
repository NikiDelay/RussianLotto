## 📋 Описание

Классическая игра «Русское Лото» для 2–4 игроков на одном устройстве (хот-сит режим). Каждый игрок получает уникальную карточку 3×9 с 15 случайными числами от 1 до 90. Игроки по очереди вытягивают числа, которые автоматически отмечаются при совпадении. Побеждает тот, кто первым закроет всю карточку. При одновременном завершении — фиксируется ничья.

## 📖 Использование

### Настройка игры

- В поле **Player 1–4** введите имена участников
- Используйте `↕` для изменения количества игроков
- Нажмите **❓ Help & Rules** для просмотра правил

### Игровой процесс

| Кнопка | Действие |
|--------|----------|
| **🎲 Draw Number** | Вытянуть случайное число (1 раз за ход) |
| **🔄 Next Player** | Передать ход следующему участнику |
| **🔙 Back to Menu** | Вернуться в главное меню |

### Визуальные индикаторы

- 🟢 **Зелёная ячейка** — число закрыто игроком
- ⚪ **Серая ячейка** — пустое поле или неотмеченное число
- 📋 **Панель истории** — последние 50 выпавших чисел (новое сверху)

### Завершение игры

- При полном закрытии карточки появляется сообщение **🏆 [Имя] WINS!**
- Если несколько игроков завершили одновременно — **🏆 Draw! [Имена] won!**
- Кнопки блокируются, игра останавливается до возврата в меню

## 📊 Логика игры

### Генерация карточки

| Параметр | Значение |
|----------|----------|
| **Размер** | 3 строки × 9 столбцов |
| **Чисел на карточке** | Ровно 15 (по 5 в каждой строке) |
| **Диапазоны столбцов** | 1–10, 11–20, 21–30, ..., 81–90 |
| **Уникальность** | Числа не повторяются в пределах одной карточки |

### Механика розыгрыша

| Компонент | Описание |
|-----------|----------|
| **Пул чисел** | 90 уникальных чисел (1–90), перемешиваются при старте |
| **Авто-маркировка** | При выпадении числа оно автоматически отмечается на всех карточках |
| **Ограничение хода** | Кнопка «Draw Number» активна только 1 раз за ход текущего игрока |
| **Проверка победы** | Выполняется после каждого вытягивания; при совпадении — фиксация результата |
